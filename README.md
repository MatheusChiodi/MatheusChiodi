## About Me

I'm the Tech Lead of the Sustentação team at **Move Mais**, a Brazilian mobility and toll payments company. My day is about keeping systems that handle real money and real traffic working: diagnosing production issues, building the processes and automations that stop them from coming back, and getting support, product and development moving in the same direction.

I came from the full stack side, so I still write code across the whole stack, with more depth on the back-end. Outside work I build developer tools, open source projects for Claude Code, and I teach programming on YouTube.
